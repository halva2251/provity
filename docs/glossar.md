# Glossar — ProVity

> B-6: alphabetisch sortiertes Glossar mit Erläuterungen der Fachbegriffe und
> Abkürzungen, die einer aussenstehenden Fachperson unbekannt sein könnten.

| Begriff | Erläuterung |
|---------|-------------|
| **App Router** | Routing-System von Next.js (ab Version 13), bei dem Ordnerstruktur unter `app/` die URL-Routen definiert. |
| **CI/CD** | Continuous Integration / Continuous Deployment — automatisiertes Prüfen (Lint, Build) und Ausliefern von Code bei jeder Änderung. |
| **Client Component** | React-Komponente, die im Browser läuft (`"use client"`); nötig für Interaktivität wie den Timer. |
| **CRUD** | Create, Read, Update, Delete — die vier Grundoperationen auf Daten. |
| **Enum** | Aufzählungstyp in PostgreSQL mit fest definierten erlaubten Werten (z.B. Priorität: niedrig/mittel/hoch). |
| **ER-Diagramm** | Entity-Relationship-Diagramm — stellt Datenbanktabellen und ihre Beziehungen grafisch dar. |
| **IPERKA** | Projektmethode in 6 Phasen: Informieren, Planen, Entscheiden, Realisieren, Kontrollieren, Auswerten. |
| **Lint / ESLint** | Werkzeug, das Code automatisch auf Stil- und Fehlerregeln prüft. |
| **Next.js** | React-basiertes Web-Framework für Frontend und Backend (Server) in einer Codebasis. |
| **PostgreSQL** | Relationales Open-Source-Datenbanksystem; bei ProVity über Supabase bereitgestellt. |
| **PWA** | Progressive Web App — eine Web-App, die sich auf dem Smartphone wie eine native App installieren lässt. |
| **RLS** | Row Level Security — PostgreSQL-Funktion, die Zeilenzugriff pro Nutzer einschränkt (Datenisolation). |
| **Server Action** | Serverseitige Funktion in Next.js (`"use server"`), die Schreibvorgänge sicher ausführt, ohne separate API. |
| **Server Component** | React-Komponente, die auf dem Server gerendert wird und Daten lädt, bevor die Seite ausgeliefert wird. |
| **Supabase** | Backend-as-a-Service auf PostgreSQL-Basis mit eingebauter Authentifizierung und RLS. |
| **Tailwind CSS** | Utility-First-CSS-Framework; Styling über vordefinierte Klassen direkt im Markup. |
| **TypeScript** | Erweiterung von JavaScript um statische Typen; reduziert Laufzeitfehler. |
| **uuid** | Universally Unique Identifier — eindeutiger Schlüssel, der als Primärschlüssel der Tabellen dient. |
| **Vercel** | Hosting-Plattform, die Next.js-Apps automatisch aus GitHub baut und deployt. |
